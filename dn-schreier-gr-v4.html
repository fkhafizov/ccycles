How to use — v2

Graph (left panel)

Vertices are 2-element subsets {i,j} of {1,…,n}. Generators: regular (t, t+1) for t=1,…,n−2 and special (n−2, n) (orange-red dashed). Click a vertex → A (blue); click another → B (orange) with shortest BFS path highlighted.

Lattice path panel (middle)

Each vertex {i,j} maps to a binary string of length n: position t is 1 if t∈{i,j}, else 0. Reading left to right: 1=↑, 0=→ gives a lattice path in the k×(n−k) rectangle.

Area between paths = Σ |y_A(x) − y_B(x)| over all right-steps x. For the standard An−1 generators (1,2),(2,3),…,(n−1,n) this always equals the graph distance — the holography is exact.

The special generator & shortcuts

Our generating set replaces (n−1,n) with the non-adjacent transposition (n−2,n). This swaps positions n−2 and n in the binary string, skipping position n−1. One application moves two steps' worth of lattice-path displacement in a single graph step, so it acts as a shortcut: it costs distance 1 but reduces the area by 2.

Example (n=6): A=(4,5) → 000110, B=(5,6) → 000011. Area between paths = 2, but generator (4,6) connects them directly, so d(A,B) = 1. Result: Area − d = 1.

Whenever the footer shows ✗ Area > d, the shortest path used the special generator at least once. The difference Area − d counts how many "free steps" the shortcut provided. This deviation is the signature of the Dn branching — it vanishes for all pairs when the full standard An−1 generators are used instead.

Claim: exact offset rules assuming A < B lexicographically (verified for n = 5–9)

Write A = {a₁,a₂} and B = {b₁,b₂} with a₁<a₂, b₁<b₂, A<B lex. Define two conditions:

xor-n: exactly one of A, B contains n.
cross: one of {A,B} contains n−1 but not n, and the other contains n but not n−1 — i.e. the two vertices "swap" the roles of n−1 and n exclusively.

Offset = +1  ⟺  xor-n holds AND cross does NOT hold.
Plain language: exactly one vertex contains n, but they do NOT form a "{n−1, n} swap" pair. This happens in two sub-cases: (a) B contains n, and A does not contain n−1; or B contains both n and n−1; or (b) A contains n (so A = (i,n) with i<b₁), and B contains neither n−1 nor n.

Offset = −1  ⟺  cross holds.
Plain language: one vertex is of the form (i, n−1) and the other is (j, n), with neither containing the other's "partner" element. Since A<B lex, this means either A=(i,n−1), B=(j,n) with i<j, or A=(i,n), B=(j,n−1) with i<j.

Offset = 0  ⟺  xor-n does NOT hold — neither or both of {A,B} contain n. The special generator plays no role in the shortest path.
