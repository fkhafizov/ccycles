Consecutive 4-Cycle Moves

Custom Strings (X / Y Mode)

Switch to Custom (X, Y) and type your start string X. Y is automatically inferred as the canonical sort target (all 1s before all 0s). Use 🎲 Randomize Y for a random permutation of X's bits. Accepted formats: 000111, 0,0,0,1,1,1, or space-separated. X must have length 4–14 with at least one 0 and one 1.

The Problem

Find the shortest sequence of consecutive 4-cycle generators transforming X into Y in the Schreier coset graph G₄(k, n) = Sn / (Sk × Sn−k). BFS guarantees the minimum-length path.

A = 0k1n−k (default start)   A* = 1n−k0k (default target)

Generators

σi is a cyclic permutation acting on the 4-window at positions i, i+1, i+2, i+3. Since σi has order 4, its three non-identity powers serve as generators of the Schreier coset graph G₄(k, n):

σi (right-rotate): (a,b,c,d) ↦ (d,a,b,c)
σi² (half-rotate): (a,b,c,d) ↦ (c,d,a,b)
σi⁻¹ (left-rotate): (a,b,c,d) ↦ (b,c,d,a)

For a string of length n, the position index runs i = 0, …, n−4, giving 3(n−3) total generator instances (n−3 per type). Together they connect all C(n, k) binary strings of the same Hamming weight.

Use the ⚙ Generators button to choose which types are active. Default (v12): σi and σi−1 only. Removing a type changes the graph structure and may increase path lengths or make some pairs unreachable.

Lattice Path & U Metric

Each binary string maps to a lattice path: step right for '0', step up for '1'. The shaded area beneath the path equals U = I(B), the Mann-Whitney U statistic — it counts inversions between 0-positions and 1-positions. The lattice path updates at every step, reflecting the current string.

Graph Info

After Start, the panel shows: |V| = C(n,k), |E| (counted exactly), graph diameter (computed for small graphs), d₄(X,Y) (BFS path length), d₄(A,X), d₄(A,Y) (BFS from canonical A), and No(X,Y) (number of shortest paths).

The d₄(A,·) filter lists all nodes at a given BFS distance from A, with Copy and "Use as Y" buttons.
