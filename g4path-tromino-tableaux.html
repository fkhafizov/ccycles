Tromino tableaux and shortest paths in the Schreier graph of 4-cycles

The G₄ analogue of the Young and domino tableau pictures. In G₄ (cyclic shifts of four adjacent letters) a move adds or removes one of six pieces of the holographic staircase: a single square, a vertical or horizontal domino, a diagonal pair, or a vertical or horizontal straight tromino. A shortest path that only adds pieces is a numbered tiling of R(X,Y) whose prefixes are staircases (a G₄-tableau). When d = |R|/3 every shortest path is a straight-tromino tableau; in general a few shortest paths also remove cells, and these are marked.

What is shown here

Graph. Vertices are binary words of length n with k zeros. An edge is a cyclic shift of four adjacent letters (the action of the 4-cycle (i, i+1, i+2, i+3) or its inverse). G₄(k, n) can be disconnected (for example G₄(2,4)); X and Y must lie in the same component.

Shape. ai = number of 1s to the left of the i-th zero; column i has height ai. If a(X) ≤ a(Y) componentwise, R(X,Y) is the skew shape between the two staircases (red dashed = X, blue = Y).

Moves. Every move either adds or removes one of six pieces. Adding moves: 0111 → 1110 (vertical tromino), 0001 → 1000 (horizontal tromino), 0110 → 1100 and 0011 → 0110 (vertical domino), 0011 → 1001 and 1001 → 1100 (horizontal domino), 0101 → 1010 (diagonal pair), and 0111 → 1011, 1011 → 1101, 1101 → 1110, 0001 → 0010, 0010 → 0100, 0100 → 1000 (single square). The reverse shifts remove the same pieces. Straight trominoes can always be added when the staircase allows them; the other pieces depend on the neighbouring letters.

Lower bounds. A move changes at most 3 cells, so d ≥ ⌈|R|/3⌉. Colour cell (i, r) by (i + r) mod 3: every piece has at most one cell of each colour, so d ≥ max κc, the largest colour class of R. Neither bound is exact in general.

Tableau. A G₄-tableau of shape R is a numbering of R by pieces 1, …, s, added one at a time by G₄ moves, so that after each step the filled part is again a staircase. A shortest path that only adds pieces gives a tableau with d pieces, and conversely. If d = |R|/3 (for instance if every ai is a multiple of 3 and X = A), every shortest path adds straight trominoes only.

Non-monotone paths. Unlike G₃, a shortest path in G₄ can remove cells: for X = 0111, Y = 1101 the path 0111 → 1110 → 1101 adds a vertical tromino and then removes a cell. Such paths are marked ↺ and are not tableaux; removed cells are drawn dashed with the label −t. The count of tableaux is computed separately (by adding admissible pieces to staircases) and compared with the number of shortest paths that only add pieces.

Range. Need n ≥ 4, 1 ≤ k ≤ n − 1 and C(n,k) ≤ 200,000. The graph is not drawn if the interval has more than 260 vertices; the gallery shows the first 120 paths.
