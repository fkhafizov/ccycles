G₄(k, n) — Schreier Graph Visualizer

consecutive 4-cycle Schreier graph · v25

What is G₄(k, n)?

G₄(k, n) is the Schreier coset graph of the symmetric group Sₙ with respect to the subgroup S_k × S_{n−k} and the generating set of all consecutive 4-cycles and their powers.

Vertices: all binary strings of length n with exactly k zeros — equivalently, cosets of S_k × S_{n−k}. Total: C(n, k) vertices.

Canonical A = 0⁰…0 1¹…1 (k zeros then n-k ones) A* = 1¹…1 0⁰…0 (antipodal node)

Generators (2 or 3 types per window position i)

At each window position i (0 ≤ i ≤ n−4), the four-cell window (s[i], s[i+1], s[i+2], s[i+3]) is acted on by:

σᵢ RIGHT-rotate (a,b,c,d) → (d,a,b,c) ▶ solid line [always on] σᵢ⁻¹ LEFT-rotate (a,b,c,d) → (b,c,d,a) ◀ dashed line [always on] σᵢ² HALF-rotate (a,b,c,d) → (c,d,a,b) ● dotted line [optional — enable before Generate]

By default only σᵢ and σᵢ⁻¹ are used (2 generators per position). Check Use half-rotate (σᵢ²) before clicking Generate to add σᵢ² as a third generator. Edge colour encodes window position i; edge style encodes generator type.

Distance & Holography

No closed-form distance formula is known for G₄. All distances d₄(A, B) are computed by BFS from A at graph-build time.

Mann-Whitney U statistic: U = I(B) = Σᵢ (pos(zᵢ) − i) equals the pink shaded area under the lattice path of B — also called the AUC (Area Under the Curve). The lattice path steps right for each '0' bit and up for each '1' bit.

Holography annotations shown under each lattice map:

I = area under lattice path (= AUC = U) ⌈I/3⌉ = ceiling of I/3 h = d − ⌈I/3⌉ (holographic residual)

Click ◻ Holography then click a node to see its k×(n−k) lattice diagram. Enable Show all holography to display grids on every node simultaneously.

Node Coloring Modes

  • By degree: blue (low) → red (high). Max degree = 3(n−3).
  • d from A: green (d=0) → red (d=diam). BFS-based.
  • d from A*: same gradient from the antipodal node.
  • d from clicked: click any node to set BFS source.
  • Nₒ from A: heatmap of shortest-path count (log scale).

Click 📏 d(X,Y), then click or type two node labels. Computes: exact BFS distance, Nₒ (shortest paths count), Nₚ (all simple paths, capped at 10⁶), and Hamming bounds ⌈H/2⌉ ≤ d ≤ H.
